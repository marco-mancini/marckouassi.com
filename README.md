# marckouassi.com

Portfolio personnel de Marc Kouassi — directeur artistique.

## Modifier le contenu
La page est statique et sans dépendances. Modifiez `index.html` pour les textes et les images, et `styles.css` pour la présentation. Les informations provisoires (projets, parcours, portrait et coordonnées) sont signalées dans la page.

## Publication sur GitHub Pages
Le workflow `.github/workflows/pages.yml` publie automatiquement le site à chaque mise à jour de `main`. Dans les paramètres du dépôt, choisissez **Settings → Pages → Build and deployment → Source: GitHub Actions**. Après la première exécution, le site sera disponible à l’adresse GitHub Pages du dépôt.
