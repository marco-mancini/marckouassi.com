# marckouassi.com

Portfolio personnel de Marc Kouassi, directeur artistique.

## Structure

```text
Backend/              Réservé à une future interface de programmation
Deploy/               Notes sur la publication
Design_System/        Styles CSS, jetons, animations, composants et ressources
Docs/                 Documentation éditoriale
Frontend/             Page et interactions du site
Public/images/        Emplacement des visuels locaux
.github/workflows/    Flux Pages (emplacement requis par GitHub)
```

Le site est statique et ne nécessite aucune dépendance à installer. Les feuilles de style sont organisées dans le système de design. Le flux de publication assemble l’interface du site, le système de design et les visuels publics dans l’artefact GitHub Pages. Les composants React sont des bases réutilisables pour une évolution ultérieure ; ils ne sont pas nécessaires à la publication de la page actuelle.

Les projets, dates, parcours, portrait et coordonnées à confirmer sont signalés dans la page. Consulte la [liste des contenus à personnaliser](Docs/CONTENT_CHECKLIST.md).
