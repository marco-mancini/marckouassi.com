# Composants

Chaque composant React partagé est défini dans un fichier `.tsx` accompagné de sa feuille de style `.css`. `Bouton.tsx` et `Bouton.css` fournissent un exemple de départ.

La page publique actuelle est un document HTML statique et ne compile pas ces composants. Ils pourront être repris si une interface React est introduite.
